Questions

Is VeilBrowser really free?

Yes. The current version is free to download and use. Paid extras may come later, but profiles, fingerprints and proxies are free now.

Do I need an account to use the app?

Yes — one free account. Sign up on this website or inside the app; the same email and password then work in both places.

Which Windows versions are supported?

Windows 10 and Windows 11, 64-bit.

Windows shows a SmartScreen warning. Is it safe?

VeilBrowser is a new, independently built app, so Windows shows a caution message on first install. Choose More info → Run anyway to continue. You can verify your download with the SHA-256 hash shown above.

Can I use my own proxies?

Yes. Every profile can carry its own HTTP or SOCKS5 proxy, and the built-in checker tests it before launch.
